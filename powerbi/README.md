# Power BI Dashboard
This folder contains the Power BI component of the myAkili Kids Impact Analytics portfolio project.

## Dashboard Pages

### 1. Executive Overview
Provides a high-level view of:
- Total participants
- Programme sites
- Sessions delivered
- Attendance rate
- Average score gain
- Programme reach by site
- Pre- and post-assessment performance
- Attendance performance by site

### 2. Participant & Learning Analysis
Explores:
- Average pre- and post-assessment scores
- Average score improvement
- Learning outcomes by age group
- Learning outcomes by gender
- Participant composition by age group and gender

## Data Note

The dashboard uses a synthetic dataset created for portfolio demonstration purposes. It does not contain confidential participant-level data from the actual myAkili Kids programme.
