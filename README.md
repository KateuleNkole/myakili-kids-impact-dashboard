# myAkili Kids — Impact Dashboard

**Status: In progress**

## About the programme
myAkili Kids is a digital financial literacy programme run by Hitalys
Consulting Services, reaching 800+ children across 5+ schools in Zambia.

## Business question
How is the programme performing across schools — in terms of reach,
session attendance, and improvement in financial literacy scores from
before to after the programme?

## Approach
- Data: simulated dataset reflecting real programme structure
  (schools, sessions, pre/post assessments, alumni engagement).
  Simulated because real participant data is confidential.
- Cleaning and preparation: Python
- Analysis: SQL
- Dashboard: Power BI

## Author
Kateule Nkole Mwanza — led partnerships and coordination for myAkili

AI tools (Claude, GitHub Copilot) are used to support learning and
